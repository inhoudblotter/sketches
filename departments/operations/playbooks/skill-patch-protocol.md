# Skill: Patch Protocol (Точечная Доработка Без Памяти)

**Цель:** Механизм, которым оркестратор передаёт саб-агенту точечную доработку ПОСЛЕ того, как саб-агент уже завершил домен. Саб-агенты не имеют памяти между вызовами — доработка передаётся файлом, на который явно указывает вызов, а не отдельным сканированием диска.

Контракт файла: `departments/operations/contracts/patch_template.yaml`.
Место: `workspace/{dept}/{scope}/patches/{patch_name}.yaml` — один файл = одно действие. `{scope}` (например `domains/{domain}`, `research/technical-context`) зафиксирован в системном промпте саб-агента-получателя и оркестратору знать его не обязательно за пределами того, что он пишет патч туда же, куда саб-агент его ожидает. `{patch_name}` — произвольное kebab-case имя по теме патча (не обязательно имя агента), например `tech-scout-quorum-conflict.yaml`.

## Оркестратор

1. Нашёл точечный пробел в уже успешно завершённом домене/отчёте — `<write contract="patch_template.yaml">` новый файл `{scope}/patches/{patch_name}.yaml`.
2. Вызови саб-агента тем же Brief Delegation, добавив в invocation_contract **только имя файла**: `PATCH: {patch_name}.yaml` — не полный путь.

Пробел не найден (домен вообще не выполнен, `status: MISSING`) — это не патч, обычный повторный вызов без `PATCH`.

## Саб-агент

В системном промпте саб-агента путь к патчам уже статичен, с плейсхолдером имени файла: `<read optional="true">workspace/{dept}/{scope}/patches/{PATCH}</read>` (аналогично подстановке `{WORKSPACE_ROOT}`). Если `PATCH` передан в invocation — это Patch Run: адресуй только `gap_type` из прочитанного файла, `<write>` его же обратно с обновлённым `status: applied|failed` + `result_note` (файл не удалять), и сразу заверши работу — остальной workflow не выполняется. `PATCH` не передан — `<read optional="true">` ничего не находит, обычный Fresh Run.

## Anti-Patterns

- ❌ Патч при `status: MISSING` — нечего патчить, просто повторный вызов.
- ❌ Удалять файл патча после применения.
- ❌ Один файл на несколько доменов/действий.
- ❌ `status: failed` без `result_note`.
- ❌ Передавать в `PATCH` полный путь вместо только имени файла.
